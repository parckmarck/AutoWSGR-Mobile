# AutoWSGR Mobile

Android APK migration prototype for AutoWSGR.

## Build

Run from this directory on Windows with Android SDK installed:

```powershell
.\build-apk.ps1
```

The script builds and signs a debug APK under `build/dist/`.

## Scope

This project contains the Android control panel, MediaProjection capture service, accessibility tap bridge, native recognizers, normal sortie MVP, and collect-only expedition automation aligned with the original AutoWSGR logic.
